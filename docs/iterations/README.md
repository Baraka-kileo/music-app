# Iteration screenshots

Emulator captures taken while building, kept to compare versions over time.

- `early/` — first rounds: onboarding, home, library, look picker, player passes (full resolution).
- `player-and-pages/` — Classic player, cards, lyrics, queue, clips, search, in-app video (full resolution).
- `audit/` — later rounds at 360×800 (tap coordinates × 3 = device pixels), mostly the Immersive look.

Helper scripts used for these rounds (screenshot, patch and compare scripts) are in `tools/session-scripts/`.
